# Кинотеатр на колёсах

«Кинотеатр на колёсах» — дипломный Laravel 10 проект для демонстрации работы выездного кинотеатра по городам Татарстана. Система объединяет афишу мобильного кинофургона, карту маршрута, голосование жителей, демо-покупку билетов с QR-кодом и административную панель для управления показами.

## Функционал

### Для пользователя

- регистрация, вход, выход и восстановление пароля;
- просмотр главной страницы, страницы «О проекте», афиши, фильмов и карты маршрута;
- поиск фильмов по названию, фильтрация по городу, жанру и возрастному рейтингу;
- голосование за фильм и указание ожидаемого количества зрителей;
- покупка демо-билетов на ближайшие показы;
- страница «Мои билеты» со статусами «Оплачен» и «Возвращён», суммой, временем сеанса и QR/демо-кодом;
- возврат купленного билета.

### Для администратора

- просмотр KPI по пользователям, голосам, билетам и загрузке мест;
- быстрые действия для добавления фильмов, городов и перехода к витрине;
- просмотр ближайших сеансов и статуса фильма: «Сегодня», «Запланирован», «Прошёл»;
- выбор текущего города кинофургона вручную или автоматически по спросу;
- настройка дедлайна голосования и цены билета;
- создание, редактирование, дублирование и удаление фильмов;
- управление городами маршрута;
- анализ голосов и ожидаемых зрителей по городам.

## Технологии

- PHP 8.1+;
- Laravel 10;
- Blade и Eloquent ORM;
- Vite для сборки `resources/css/app.css` и `resources/js/app.js`;
- MySQL или SQLite для локальной демонстрации;
- CSS с адаптивной вёрсткой.

## Запуск проекта

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed
php artisan storage:link
npm install
npm run build
php artisan serve
```

После запуска откройте адрес, который покажет `php artisan serve` (обычно `http://127.0.0.1:8000`). В продакшен-сценарии стили подключаются через Vite из `resources/css/app.css`; резервный файл `public/css/app.css` используется только если сборка `public/build/manifest.json` отсутствует.

## Демо-данные

Команда `php artisan migrate:fresh --seed` создаёт города маршрута, фильмы, пользователей, голоса, билеты и настройки системы. Часть фильмов специально не имеет постера — для них интерфейс показывает аккуратный fallback-блок.

## Финальная проверка перед демонстрацией

```bash
php artisan route:list
php artisan migrate:fresh --seed
npm run build
php artisan serve
```
