# Кинотеатр на колёсах

Дипломный Laravel-проект выездного кинотеатра по городам Татарстана. Приложение показывает афишу мобильного кинофургона, маршрут поездки, голосование жителей за фильмы, покупку билетов и административную статистику для управления показами.

## Возможности пользователя

- регистрация и вход в личный кабинет;
- просмотр главной страницы, афиши, фильмов и карты маршрута;
- выбор города и голосование за фильм;
- просмотр даты, площадки, вместимости и заполненности сеанса;
- покупка демо-билетов и просмотр билетов в профиле;
- возврат купленного билета из личного кабинета.

## Возможности администратора

- просмотр KPI: пользователи, голоса, билеты, загрузка мест;
- выбор текущего города кинофургона вручную или по спросу;
- настройка дедлайна голосования и цены билета;
- добавление, редактирование, дублирование и удаление фильмов;
- управление городами маршрута;
- анализ топ-фильма и топ-города по голосам.

## Технологии

- Laravel 10;
- PHP 8.1;
- MySQL;
- Blade;
- CSS;
- JavaScript;
- Vite.

## Запуск проекта

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
npm install
npm run build
php artisan serve
```

После запуска сайт будет доступен по адресу, который выведет команда `php artisan serve`.

## Демо-данные

Сидер создаёт города маршрута по Татарстану, фильмы с русскими названиями, голоса, настройки системы и несколько купленных билетов. Это позволяет сразу показать комиссии готовый сценарий: главная страница → афиша → голосование → карта → покупка билета → админ-панель.
