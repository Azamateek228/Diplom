# Кинотеатр на колёсах

«Кинотеатр на колёсах» — дипломный Laravel 10 проект для демонстрации работы выездного кинотеатра по городам Татарстана. Система объединяет афишу мобильного кинофургона, карту маршрута, голосование жителей, демо-покупку билетов с QR/демо-кодом и административную панель для управления показами.

## Что доработано для защиты

- приведена единая тёмная кинематографичная тема для витрины, афиши, профиля, билетов, админ-панели и форм;
- добавлены локальные SVG-постеры демо-фильмов, чтобы проект не зависел от внешних CDN/API;
- добавлены глобальные toast-уведомления для успешных действий, ошибок и предупреждений;
- улучшены голосование, состояния закрытого голосования и подсказка выбора города;
- оформлена демонстрационная оплата с серверной проверкой номера карты по алгоритму Луна, срока действия, CVV, держателя карты и остатка мест;
- билеты получили понятный статус, сумму, код билета, demo QR-блок и правило возврата за 24 часа;
- Vite подключает актуальные `resources/css/app.css` и `resources/js/app.js`, поэтому после `npm run build` применяются свежие стили и скрипты;
- добавлены feature-тесты ключевых сценариев: голосование, покупка, ошибки карты, sold out и возврат.

## Функционал

### Для пользователя

- регистрация, вход, выход и восстановление пароля;
- просмотр главной страницы, страницы «О проекте», афиши, фильмов и карты маршрута;
- поиск фильмов по названию, фильтрация по жанру и возрастному рейтингу;
- голосование за фильм в рамках выбранного города;
- покупка демо-билетов на ближайшие показы;
- страница «Мои билеты» со статусами «Оплачен» и «Возвращён», суммой, временем сеанса и кодом билета;
- возврат купленного билета, если до показа осталось больше 24 часов.

### Для администратора

- просмотр KPI по пользователям, голосам, билетам и загрузке мест;
- быстрые действия для добавления фильмов, городов и перехода к витрине;
- выбор текущего города кинофургона вручную или автоматически по спросу;
- настройка дедлайна голосования и цены билета;
- создание, редактирование, дублирование и удаление фильмов;
- управление городами маршрута;
- анализ голосов и ожидаемой заполняемости по городам.

## Технологии

- PHP 8.1+;
- Laravel 10;
- Blade и Eloquent ORM;
- Vite для сборки `resources/css/app.css` и `resources/js/app.js`;
- MySQL или SQLite для локальной демонстрации;
- CSS с адаптивной вёрсткой;
- vanilla JS без тяжёлых frontend-фреймворков.

## Запуск проекта

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate:fresh --seed
php artisan storage:link
npm install
npm run build
php artisan serve
```

После запуска откройте адрес, который покажет `php artisan serve` (обычно `http://127.0.0.1:8000`). В продакшен-сценарии стили подключаются через Vite из `resources/css/app.css`; резервный файл `public/css/app.css` используется только если сборка `public/build/manifest.json` отсутствует.

## Демо-оплата

Проект не подключает реальный платёжный шлюз. Деньги не списываются, а введённые реквизиты используются только для демонстрационной валидации формы.

- CVV и полный номер карты не сохраняются в базу данных.
- Сервер проверяет номер карты: удаляет пробелы/дефисы, проверяет 16–19 цифр и контрольную сумму по алгоритму Луна.
- Сервер проверяет срок действия в формате `MM/YY` или `MM/YYYY`, месяц `01–12` и то, что карта не истекла.
- Сервер проверяет CVV из 3–4 цифр, имя держателя и количество билетов с учётом свободных мест.
- Для демонстрации можно использовать карту `4242 4242 4242 4242`, любой будущий срок действия и CVV `123`.

## Что показать на защите

1. Войти под пользователем `user@example.com` / `password`.
2. Открыть профиль и показать выбранный город зрителя.
3. Перейти в «Фильмы» и проголосовать за фильм: после redirect появится toast «Ваш голос учтён».
4. Открыть «Афишу» и показать, что маршрут и показы строятся по городам Татарстана.
5. Купить демо-билет: показать блок «Демо-оплата», маски полей и итоговую сумму.
6. После покупки открыть профиль → «Мои билеты»: показать статус «Оплачен», сумму и код/демо QR-блок.
7. Показать возврат билета, если до сеанса больше 24 часов, и уведомление об успешном возврате.
8. Войти под администратором `admin@example.com` / `password`.
9. Открыть админ-панель: KPI, аналитику голосов, ожидаемую заполняемость, управление фильмами и городами.

## Демо-данные

Команда `php artisan migrate:fresh --seed` создаёт города маршрута, фильмы с локальными SVG-постерами, пользователей, голоса, билеты и настройки системы. В нормальном демонстрационном сценарии fallback-постеры почти не используются.

## Финальная проверка перед демонстрацией

```bash
php artisan route:list
php artisan migrate:fresh --seed
php artisan test
npm run build
php artisan serve
```

## 2FA и сброс пароля

Двухфакторная аутентификация и самостоятельный сброс пароля временно отключены, чтобы не зависеть от SMTP во время демонстрации. Вход работает по логину и паролю, профиль, билеты, голосование, афиша и админка остаются без изменений.
