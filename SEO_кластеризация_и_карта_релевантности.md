## 3. РЕКОМЕНДАЦИИ ПО КОНТЕНТУ

### Для главной страницы:
- Добавить текст о проекте (200-300 слов)
- Упоминание городов показа
- Информация о бесплатном посещении
- Призывы к действию (CTA)

### Для страницы фильмов:
- Описание механизма голосования
- Информация о формировании рейтинга
- Фильтры по жанрам и городам

### Для страницы маршрута:
- Информация о формировании маршрута
- Контакты для организации показов
- FAQ для посетителей

## 5. МИКРОРАЗМЕТКА SCHEMA.ORG

### Используемые типы:
- `LocalBusiness` — организация
- `Movie` — фильмы
- `Event` — мероприятия/показы
- `BreadcrumbList` — навигация
- `WebSite` — сайт

### Пример для фильма:
```json
{
  "@context": "https://schema.org",
  "@type": "Movie",
  "name": "Название фильма",
  "genre": "Жанр",
  "duration": "PT120M",
  "contentRating": "16+",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "8.5",
    "ratingCount": "150"
  }
}
```
