# Тезисы для защиты проекта «Кинотеатр на колёсах»

## 1. Цель проекта

Цель проекта — сделать веб-приложение для передвижного кинотеатра, который приезжает в разные города Татарстана и показывает фильмы на открытых площадках.

Система помогает зрителям заранее посмотреть фильмы, проголосовать за интересные показы, увидеть маршрут кинотеатра и купить билет.

## 2. Актуальность

Не во всех небольших городах есть удобный доступ к современному кинотеатру. Передвижной кинотеатр решает эту проблему: он может приезжать туда, где есть интерес зрителей.

Проект актуален, потому что объединяет культурное мероприятие, онлайн-голосование и удобное планирование маршрута.

## 3. Роли пользователей

### Гость

Гость может открыть сайт, посмотреть список фильмов, афишу и карту маршрута.

### Пользователь

Пользователь может зарегистрироваться, выбрать свой город, голосовать за фильмы, покупать билеты и видеть свои билеты в профиле.

### Администратор

Администратор управляет данными проекта: городами, фильмами, текущим городом маршрута и статистикой по голосам, билетам и ожидаемым зрителям.

## 4. Основные функции

- Просмотр фильмов с жанром, описанием, возрастным рейтингом, площадкой показа и постером.
- Голосование за фильм в выбранном городе.
- Построение маршрута кинотеатра по городам Татарстана.
- Афиша ближайших показов по маршруту.
- Покупка билетов на выбранный сеанс.
- Возврат билетов с ограничением по времени.
- Профиль пользователя с личными данными, городом и билетами.
- Админ-панель со статистикой по фильмам, городам, голосам и билетам.

## 5. Как работает длинный маршрут

Длинный маршрут используется, когда в системе ещё нет голосов зрителей.

В этом случае кинотеатр строит полный маршрут по всем городам Татарстана, которые есть в базе данных. Города сортируются по полю `route_order`, поэтому порядок заранее понятный и совпадает со списком на карте.

Так комиссия может увидеть, что проект работает даже до начала голосования.

## 6. Как работает короткий маршрут

Короткий маршрут используется, когда в системе уже есть хотя бы один голос.

В этом случае в маршрут попадают только те города, где зрители проголосовали. Если голос есть только в одном городе, на карте всё равно показывается этот город и пояснение, что маршрут построен по голосам.

Так маршрут становится более полезным: кинотеатр едет туда, где есть интерес зрителей.

## 7. Как работает возврат билетов

Пользователь может вернуть билет только заранее.

Если до начала показа осталось больше 24 часов, возврат доступен. Если осталось меньше 24 часов или сеанс уже прошёл, возврат запрещён.

В профиле показывается дата и время, до которых можно оформить возврат. Если срок прошёл, кнопка возврата не показывается, а пользователь видит понятное сообщение.

## 8. Использованные технологии

- Laravel 10 — основа серверной части проекта.
- PHP 8.1 — язык программирования серверной логики.
- MySQL — база данных для пользователей, фильмов, городов, голосов и билетов.
- Blade — шаблоны страниц.
- CSS — оформление интерфейса.
- JavaScript — интерактивные элементы на страницах.
- Leaflet — отображение карты и маршрута кинотеатра.

## 9. Что можно показать на демонстрации

1. Открыть главную страницу и показать идею проекта.
2. Перейти в раздел фильмов и показать карточки фильмов.
3. Открыть карту и объяснить тип маршрута.
4. Показать список городов под картой и сказать, что порядок совпадает с линией маршрута.
5. Перейти в афишу и показать расписание по городам маршрута.
6. Купить билет на сеанс.
7. Открыть профиль и показать билет, QR-код и срок возврата.
8. В админ-панели показать статистику по городам, фильмам, голосам и билетам.
