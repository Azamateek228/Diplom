## 3. ПОШАГОВАЯ ИНСТРУКЦИЯ ПО РАЗМЕЩЕНИЮ

### Этап 1: Подготовка проекта

```bash
# 1. Создать production .env файл
cp .env .env.production

# 2. Изменить настройки для production
# В .env.production:
APP_ENV=production
APP_DEBUG=false
APP_URL=https://kinokolesa.ru

APP_KEY=base64:... (сгенерировать на хостинге)

DB_CONNECTION=mysql
DB_HOST=localhost
DB_DATABASE=kinokolesa_db
DB_USERNAME=kinokolesa_user
DB_PASSWORD=secure_password_123

# 3. Оптимизировать проект
composer install --optimize-autoloader --no-dev
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

### Этап 2: Загрузка на хостинг

#### Вариант A: Через Git (рекомендуется)

```bash
# На хостинге (через SSH):
cd /home/u/username/kinokolesa
git clone https://github.com/username/kinokolesa.git .
composer install --optimize-autoloader --no-dev
```

#### Вариант B: Через FTP/SFTP

```
1. Архивировать проект:
   zip -r kinokolesa.zip . -x ".git/*" -x "node_modules/*" -x "vendor/*"

2. Загрузить архив на хостинг

3. Распаковать:
   unzip kinokolesa.zip

4. Установить зависимости:
   composer install --optimize-autoloader --no-dev
```

### Этап 4: Настройка веб-сервера

#### Для Apache (.htaccess уже есть в public/):

```apache
# /public/.htaccess
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On

    # Handle Authorization Header
    RewriteCond %{HTTP:Authorization} .
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

    # Redirect Trailing Slashes If Not A Folder...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_URI} (.+)/$
    RewriteRule ^ %1 [L,R=301]

    # Send Requests To Front Controller...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
```

#### Для Nginx:

```nginx
server {
    listen 80;
    server_name kinokolesa.ru www.kinokolesa.ru;
    root /home/u/username/kinokolesa/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

### Этап 6: Финальная настройка

```bash
# 1. Сгенерировать APP_KEY:
php artisan key:generate

# 2. Настроить права доступа:
chmod -R 755 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache

# 3. Очистить кеш:
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

# 4. Создать кеш конфигурации:
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

## 9. БЕЗОПАСНОСТЬ

### Обязательные меры:

1. **HTTPS:** Включить принудительный редирект
2. **APP_KEY:** Уникальный для production
3. **APP_DEBUG:** false (никогда true в production!)
4. **Права доступа:** 755 для директорий, 644 для файлов
5. **Доступ к .env:** Запретить через веб-сервер
6. **SQL инъекции:** Использовать Eloquent ORM
7. **XSS защита:** Blade автоматически экранирует вывод

### Для Apache (.htaccess):

```apache
# Запретить доступ к .env
<Files .env>
    Order allow,deny
    Deny from all
</Files>

# Запретить доступ к .git
<Directory ~ "/\.git">
    Order allow,deny
    Deny from all
</Directory>
```
